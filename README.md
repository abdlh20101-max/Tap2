# X-Play - منصة الألعاب العالمية المتكاملة

## نظرة عامة
**X-Play** هي منصة ألعاب 2D متكاملة مبنية بمحرك Unity 2022.3.62f3، تتضمن 10 ألعاب متنوعة وإدمانية مع نظام عملات موحد وإدارة طاقة.
Developed by: Abdullah Al-husini

## المميزات الرئيسية

### 1. نظام الواجهة الرئيسية
- **خلفية 3D متحركة** لتجربة بصرية جذابة
- **نظام إعلانات متقدم:**
  - بنر سفلي يتغير تلقائياً كل 7 ثوان
  - بوب-أب إعلاني كل 20 ثانية (مدة 5 ثوان لكل إعلان)
  - منطقة نقر محدودة في زاوية البنر العليا اليمنى
- **عرض العملات والطاقة** في الأعلى
- **قائمة الإعدادات** للتحكم بالموسيقى والصوت

### 2. نظام العملات والطاقة
- **العملات (Coins):** تُكتسب من لعب الألعاب
- **الطاقة (Energy):** تُستهلك عند بدء لعبة، وتُشحن تدريجياً بمرور الوقت
- **حفظ البيانات:** يتم حفظ جميع البيانات محلياً عبر PlayerPrefs

### 3. الموسيقى والصوت
- **موسيقى خلفية هادئة وناعمة** بدون كلام
- **مستمرة من Intro إلى جميع المشاهد**
- **إعدادات التحكم بالصوت والموسيقى**

## الألعاب العشر

### 1. **Pulse Clicker**
- 4 أوضاع مختلفة:
  - **السنتر:** دائرة ثابتة في المنتصف
  - **الدائرة المتحركة:** دائرة تتحرك يميناً ويساراً
  - **التصاعد:** دائرة تتحرك لأعلى بسرعة متزايدة
  - **تجاوز العقبات:** حركة عشوائية معقدة
- **الهدف:** النقر على الدائرة بدقة
- **المكافآت:** 10 عملات لكل نقرة صحيحة

### 2. **Golden Harvest**
- **الميكانيكية:** زراعة المحاصيل وحصادها
- **نظام النمو:** المحصول ينمو تدريجياً (10 ثوان)
- **البيع:** بيع المحاصيل لجمع العملات
- **المكافآت:** 25 عملة لكل حصاد

### 3. **Neon Pop**
- **الميكانيكية:** تفجير الفقاعات الملونة
- **نظام Combo:** كل فقاعة متتالية تزيد المضاعف
- **المكافآت:** 15 عملة × مضاعف Combo

### 4. **Cyber Slither**
- **الميكانيكية:** توجيه الثعبان لجمع الطعام
- **النمو:** الثعبان ينمو مع كل طعام
- **التحديات:** الاصطدام بالجدران أو الجسم ينهي اللعبة
- **المكافآت:** 20 عملة لكل طعام

### 5. **Block Crush**
- **الميكانيكية:** ترتيب المكعبات وتفجير الصفوف
- **نظام Combo:** تفجير متتالي يزيد المضاعف
- **المكافآت:** 50 عملة لكل صف × مضاعف Combo

### 6. **Sky Stacker**
- **الميكانيكية:** بناء برج من قطع متحركة
- **الصعوبة:** السرعة تزداد مع كل قطعة
- **التقاطع:** يجب التقاطع مع القطعة السابقة
- **المكافآت:** 30 عملة لكل قطعة ناجحة

### 7. **Dash Escape**
- **الميكانيكية:** الجري والقفز لتجاوز العقبات
- **جمع العملات:** التقاط العملات أثناء الجري
- **السرعة المتزايدة:** اللعبة تصبح أسرع تدريجياً
- **المكافآت:** 10 عملات لكل عملة + 5 عملات لكل متر

### 8. **Brain Storm**
- **الميكانيكية:** حل الألغاز الرياضية والمنطقية
- **الأسئلة:** متنوعة (جمع، طرح، ضرب، قسمة)
- **الوقت:** 120 ثانية لحل أكثر عدد من الألغاز
- **المكافآت:** 50 عملة لكل إجابة صحيحة

### 9. **Mind Match**
- **الميكانيكية:** تذكر تسلسل الألوان والأرقام
- **التصعيد:** التسلسل يزداد طولاً مع كل مستوى
- **الأخطاء:** خطأ واحد ينهي اللعبة
- **المكافآت:** 100 عملة لكل مستوى

### 10. **Nitro Race**
- **الميكانيكية:** قيادة سيارة وتجاوز السيارات الأخرى
- **جمع العملات:** التقاط العملات على الطريق
- **تجنب الاصطدام:** الاصطدام بسيارة أخرى ينهي اللعبة
- **المكافآت:** 15 عملة لكل عملة + 25 عملة لكل سيارة تجاوز

## متطلبات النظام

- **محرك Unity:** 2022.3.62f3
- **نظام التشغيل:** Windows, macOS, Linux
- **المنصات المدعومة:** Android, iOS, WebGL

## التثبيت والتشغيل

1. **استنساخ المستودع:**
   ```bash
   git clone https://github.com/abdlh20101-max/Tap2.git
   cd X-Play
   ```

2. **فتح المشروع في Unity:**
   - افتح Unity Hub
   - اختر "Add Project from Disk"
   - اختر مجلد X-Play
   - اختر الإصدار 2022.3.62f3

3. **تشغيل اللعبة:**
   - افتح مشهد Intro من Assets/Scenes/
   - اضغط Play

## نظام الحفظ

جميع بيانات اللاعب يتم حفظها محلياً باستخدام PlayerPrefs:
- العملات الحالية
- الطاقة الحالية
- إعدادات الموسيقى والصوت

## الإعدادات

يمكن تخصيص اللعبة عبر Inspector في Unity:
- مدة Intro
- فترات تغيير الإعلانات
- معدلات الطاقة
- أسعار العملات
