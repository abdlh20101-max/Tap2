# GamesHub - منصة ألعاب عالمية متكاملة

## 🎮 نظرة عامة

**GamesHub** هي منصة ألعاب 2D متكاملة مبنية بمحرك Unity 2022.3.62f3، تتضمن **10 ألعاب متنوعة وإدمانية** مع نظام عملات وطاقة متقدم، ونظام إعلانات ذكي، وواجهة مستخدم احترافية.

## 🎯 الألعاب المتضمنة

### 1. **النقر الصحيح** (Tap Game)
- **الوصف:** لعبة تحتاج إلى نقرات دقيقة على هدف متحرك
- **الأوضاع:** 4 أوضاع مختلفة (السنتر، الدائرة المتحركة، التصاعد، تجاوز العقبات)
- **المكافأة:** 10 عملات لكل نقرة صحيحة
- **الطاقة المطلوبة:** 10 طاقة

### 2. **مزرعة الذهب** (Farm Game)
- **الوصف:** لعبة زراعة وتجارة مع نظام النمو
- **الميكانيكية:** زراعة → انتظار النمو → حصاد → بيع
- **المكافأة:** 25 عملة لكل حصاد
- **الطاقة المطلوبة:** 15 طاقة

### 3. **صائد الفقاعات المظلمة** (Bubble Game)
- **الوصف:** تفجير فقاعات ملونة مع نظام Combo
- **الميكانيكية:** نقر الفقاعات → تفجير → جمع النقاط
- **المكافأة:** 15 عملة × مضاعل Combo
- **الطاقة المطلوبة:** 12 طاقة

### 4. **ثعبان النيون** (Snake Game)
- **الوصف:** لعبة الثعبان الكلاسيكية بأسلوب حديث
- **الميكانيكية:** توجيه الثعبان → جمع الطعام → النمو
- **المكافأة:** 20 عملة لكل طعام
- **الطاقة المطلوبة:** 10 طاقة

### 5. **مكعبات الطاقة** (Block Game)
- **الوصف:** ترتيب مكعبات وتفجير الصفوف الكاملة
- **الميكانيكية:** ترتيب → تطابق → تفجير → نقاط
- **المكافأة:** 50 عملة × عدد المكعبات × Combo
- **الطاقة المطلوبة:** 15 طاقة

### 6. **برج التوازن الرقمي** (Tower Game)
- **الوصف:** بناء برج من قطع متساقطة بدقة
- **الميكانيكية:** وضع القطعة → توازن → تقليل العرض
- **المكافأة:** 30 عملة لكل قطعة ناجحة
- **الطاقة المطلوبة:** 10 طاقة

### 7. **هروب المحترف** (Runner Game)
- **الوصف:** جري مستمر مع تجاوز عقبات وجمع عملات
- **الميكانيكية:** جري → قفز → تجنب → جمع عملات
- **المكافأة:** 10 عملات + 5 عملات/متر
- **الطاقة المطلوبة:** 12 طاقة

### 8. **لغز الأرقام** (Puzzle Game)
- **الوصف:** حل أسئلة رياضية ومنطقية
- **الميكانيكية:** سؤال → 4 خيارات → إجابة → نقاط
- **المكافأة:** 50 عملة لكل إجابة صحيحة
- **الطاقة المطلوبة:** 10 طاقة

### 9. **تحدي الذاكرة** (Memory Game)
- **الوصف:** تذكر تسلسل ألوان متزايد
- **الميكانيكية:** عرض → تذكر → إدخال → تصعيد
- **المكافأة:** 100 عملة لكل مستوى
- **الطاقة المطلوبة:** 10 طاقة

### 10. **سباق السرعة** (Race Game)
- **الوصف:** قيادة سيارة وتجنب العقبات
- **الميكانيكية:** قيادة → تجنب → جمع عملات → سرعة
- **المكافأة:** 15 عملات + 25 عملة/سيارة
- **الطاقة المطلوبة:** 15 طاقة

## 🎨 الميزات الرئيسية

- **عدم الإزعاج:** لا يعيق تجربة اللعب

- **مؤثرات صوتية:** لكل إجراء في اللعبة
- **التحكم:** تفعيل/تعطيل وتغيير مستوى الصوت
- **الإعدادات:** محفوظة محلياً

- **خلفية 3D:** متحركة وجذابة
- **قائمة الألعاب:** عرض جميع الألعاب بأيقونات واضحة

- **الانتقال السلس:** بين المشاهد والألعاب

## 🚀 البدء السريع

### 1. استنساخ المستودع
```bash
git clone https://github.com/abdlh20101-max/Tap2.git
cd GamesHub
```

### 2. فتح المشروع في Unity
- افتح Unity Hub
- اختر "Add Project from Disk"
- حدد مجلد GamesHub
- انتظر حتى يتم تحميل المشروع

### 3. تشغيل اللعبة
- اضغط على زر Play في Unity Editor
- أو اختر File > Build And Run لبناء التطبيق
